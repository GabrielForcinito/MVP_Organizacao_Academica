# 📚 Sistema de Organização Acadêmica

## 📌 Sobre o Projeto

O **Sistema de Organização Acadêmica** foi desenvolvido como um MVP (Minimum Viable Product) utilizando ferramentas de Inteligência Artificial para auxiliar estudantes na organização de tarefas, horários, provas e estudos.
O projeto foi criado durante a disciplina de **Engenharia de Prompt e Aplicações em IA**, utilizando:

* Google Stitch
* Google AI Studio
* GitHub
* Vercel

O objetivo principal do sistema é ajudar estudantes a melhorarem sua produtividade acadêmica através de uma interface moderna, simples e intuitiva.

---

# 🎯 Problema Identificado

Muitos estudantes possuem dificuldade para organizar:

* horários de aulas
* tarefas acadêmicas
* datas de provas
* trabalhos
* rotina de estudos

Isso pode causar:

* atrasos em entregas
* baixa produtividade
* desorganização
* aumento do estresse acadêmico

---

# 💡 Solução Proposta

O sistema foi desenvolvido para centralizar todas as atividades acadêmicas em um único ambiente digital.

A aplicação permite:

* gerenciamento de tarefas
* controle de horários
* calendário acadêmico
* acompanhamento de produtividade
* notificações e lembretes

---

# 🚀 Funcionalidades

## ✅ Login e Cadastro

* autenticação de usuários
* persistência de sessão
* validação de dados

## ✅ Dashboard

* resumo diário
* próximas tarefas
* horários de aulas
* acompanhamento acadêmico

## ✅ Gerenciamento de Tarefas

* adicionar tarefas
* editar tarefas
* excluir tarefas
* marcar tarefas como concluídas
* organização por prioridade

## ✅ Calendário Acadêmico

* visualização mensal
* provas e trabalhos destacados
* organização de eventos acadêmicos

## ✅ Controle de Estudos

* monitoramento de produtividade
* metas de estudo
* acompanhamento de desempenho

## ✅ Interface Moderna

* design responsivo
* navegação intuitiva
* layout limpo e organizado
